# GIT vs GITHUB

| GIT | GITHUB |
|------------|------------|
| GIT - одна из систем контроля версий   | Предоставляется Microsoft  | 
| Способ организации и поддержки версионости | Самый популярный сервис GIT | 
| Самая популярная система контроля версий  | Много полезный функций   | 
| Программа  | Огромный архив различного кода  | 

**`git clone <url>`** - *копирование загрузка удаленного репозитория, например из GITHUB*

**`git status`** - *проверка статуса git*

**`cd <name_directory>`** - *переход в другую папку  (bash)*

**`git log`** - *вывод всех коммитов*

**`git log --graph`** - *вывод всех коммитов и их визуализация*

**`git init`** - *инцилизация git*

**GITHUB таб по +** - создание нового репозитория на GITHUB и залив своей версии на GITHUB (следуем инструкции)

**`git push`** - *для подгрузки в удаленный  репозиторий*

**`git pull`** - *для подгрузки всех изменений из удаленного репозитория*

## Для работы с open-source (pull request) - добавления рекомендаций к доработке проекта

1. На GITHUB найти репозиторий и сделать fork
2. В своей папке сделать `git clone` - копируем репозиторий свой который был (fork)
3. git branch <new name_branch> и git checkount <name_branch> - делаем новую ветку и переходим на нее и там делаем изменения (это правило хорошего тона)
4. git add - добавляем для отслеживания
5. git commit  - создаем версию
6. git push - подгружаем свои  изменения в удаленный репозиторий
7. На GITHUB ждем pull request и пишем описание
